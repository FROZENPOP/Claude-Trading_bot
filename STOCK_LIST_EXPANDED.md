## Understanding Webull Option Symbols
Webull uses standardized option symbol formats that enable the trading bot to automatically detect and process options contracts:

### US Option Symbol Format:
{UNDERLYING}{YY}{MM}{DD}{C/P}{STRIKE*1000}
- Example: AAPL240119C00150000 (AAPL call option, Jan 19, 2024, $150 strike)
- Example: TSLA240216P00250000 (TSLA put option, Feb 16, 2024, $250 strike)

### Option Types Supported:
- **Calls** (C): Right to buy the underlying asset
- **Puts** (P): Right to sell the underlying asset
- **Various Expirations**: Daily, weekly, monthly, and LEAPS options
- **Range of Strikes**: From deep out-of-the-money to deep in-the-money
- **Multiple Underlyings**: Stocks, ETFs, and indices that offer options trading

The trading bot's Webull execution module automatically:
1. Detects option symbols using regex pattern matching
2. Retrieves real-time bid/ask quotes for options via MCP
3. Calculates proper position sizing (options contracts represent 100 shares)
4. Applies appropriate risk management checks for options trading
5. Submits option orders through the correct MCP endpoints
